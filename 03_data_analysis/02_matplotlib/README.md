# Matplotlib Learning Repository

A topic-by-topic practice repository based on the public W3Schools Python Matplotlib tutorial.

## Learning order

| # | Topic | What you learn |
|---:|---|---|
| 1 | [Matplotlib Introduction](./01_matplotlib_intro/README.md) | Understand what Matplotlib is and why it is used to create visualizations in Python. |
| 2 | [Getting Started](./02_getting_started/README.md) | Install Matplotlib, import it into Python, and check the installed version. |
| 3 | [Pyplot](./03_pyplot/README.md) | Use pyplot functions to create and customize figures and plots. |
| 4 | [Plotting](./04_plotting/README.md) | Learn how x and y coordinates are paired and displayed in a plot. |
| 5 | [Markers](./05_markers/README.md) | Use markers to make individual data points visible and easier to compare. |
| 6 | [Line Style](./06_line_style/README.md) | Customize plot line patterns, colors, and widths for clearer charts. |
| 7 | [Labels and Title](./07_labels_and_title/README.md) | Add a title and axis labels so readers understand what a chart represents. |
| 8 | [Grid Lines](./08_grid_lines/README.md) | Add grid lines to help readers estimate values from a chart. |
| 9 | [Subplots](./09_subplots/README.md) | Place multiple charts in one figure to compare related datasets. |
| 10 | [Scatter Plots](./10_scatter_plots/README.md) | Use scatter plots to examine relationships between two numeric variables. |
| 11 | [Bars](./11_bar_charts/README.md) | Use bar charts to compare values across discrete categories. |
| 12 | [Histograms](./12_histograms/README.md) | Use histograms to understand how numerical observations are distributed across intervals. |
| 13 | [Pie Charts](./13_pie_charts/README.md) | Use pie charts to show how categories contribute to a whole. |

## Repository structure

Each topic folder contains:
- `README.md` — one-line explanations for every included heading/subheading, a code example, and a practice task.
- `.ipynb` — Jupyter Notebook with topic outline and runnable example.
- `.py` — standalone Python script with the same example.

## Setup

Run these commands in your terminal:

```bash
python -m pip install matplotlib notebook
```

Open the repository in VS Code, then open a `.ipynb` notebook and select your Python environment. You can also run a script from the repository root:

```bash
python 02_getting_started/02_getting_started.py
```

Charts are displayed by Matplotlib; in a notebook they usually appear below the code cell.

## Learning tip

Follow the folders in numerical order. Run each example, change the data, and then try the practice task before moving to the next topic.
