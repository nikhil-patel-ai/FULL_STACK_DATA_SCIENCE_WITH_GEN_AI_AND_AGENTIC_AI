# Practice Exercises

## Beginner
1. Convert a sentence to lowercase.
2. Remove leading, trailing, and repeated spaces.
3. Split a sentence into tokens.
4. Remove a custom set of stopwords.
5. Explain stemming versus lemmatization.

## Intermediate
6. Remove URLs using `re`.
7. Decode HTML entities.
8. Replace integers and decimals with `<NUM>`.
9. Compare NLTK stemming and lemmatization on the same words.
10. Explain why `not` should often be preserved for sentiment analysis.

## Advanced
11. Design different preprocessing rules for sentiment analysis and named-entity extraction.
12. Write a reusable cleaning function with unit tests.
13. Explain why emoji removal can reduce sentiment information.
14. Identify three failure cases for a regex-based HTML cleaner.
15. Explain how to prevent data leakage when preprocessing text for ML.

## Answer format
For each exercise, include:
- Problem statement
- Code
- Output
- One- or two-sentence explanation

Try the questions before looking up solutions. Add your solutions to a separate practice file if you want to keep the topic README concise.
