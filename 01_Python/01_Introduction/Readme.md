## 4. Main Concepts Covered in This Section

This introduction folder focuses on the foundational topics that appear in the code files.

### 4.1 Hello World Program

The first step in learning Python is printing text to the screen.

```python
print("Hello, World!")
```

This is the most basic Python program and is used to confirm that Python is working properly.

### 4.2 Comments in Python

Comments are notes written in code to explain logic or provide information.

```python
# This is a single-line comment
```

Python ignores comments during execution, which makes code easier to understand.

### 4.3 Python Keywords

Python keywords are reserved words that have special meaning in the language.

Example:

```python
import keyword
print(keyword.kwlist)
```

This is used to view all Python keywords and check how many exist.

### 4.4 Variables

Variables are used to store values in memory.

```python
name = "Nikhil"
age = 21
```

This helps us reuse values throughout the program.

### 4.5 Case Sensitivity

Python is case-sensitive, which means:

```python
name = "Nikhil"
Name = "Patel"
```

These are treated as different variables.

### 4.6 Indentation

Python uses indentation to define blocks of code.

```python
if 10 > 5:
    print("10 is greater than 5")
```

This is important in Python and must be written correctly.

### 4.7 Arithmetic Operations

Python can also perform mathematical operations easily.

```python
print(10 + 20)
print(50 - 20)
print(5 * 4)
```
